# Mobile horizontale Navigation – UX-Befund

- Horizontale Navigation ist auf Touchgeräten grundsätzlich geeignet, braucht jedoch einen erkennbaren Überlaufindikator, weil sonst nicht sichtbar ist, dass weitere Optionen seitlich erreichbar sind.
  Quelle: https://www.experienceux.co.uk/ux-blog/a-ux-perspective-on-horizontal-scrolling/
- Für horizontal scrollbare Regionen sollen Fokus, Tastaturbedienung und die sichtbare Begrenzung des scrollbaren Bereichs berücksichtigt werden.
  Quelle: https://cerovac.com/a11y/2024/02/consider-accessibility-when-using-horizontally-scrollable-regions-in-webpages-and-apps/
- Nielsen Norman Group rät davon ab, mobile Karussells automatisch weiterzuschalten, weil dies auf kleinen Displays Interaktionen stören und das schnelle Scrollen durch Inhalte beeinträchtigen kann.
  Quelle: https://www.nngroup.com/articles/designing-effective-carousels/
